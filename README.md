### Hi, I'm Kyle 👋 — professional tinkerer, recreational breaker of things

I spent 14 years building payments systems that weren't allowed to break, so in my free time I break everything else.

- 🔧 **Taking things apart:** wired a fuel-consumption monitor into a 1995 Honda Del Sol,
  run OpenWRT on my network gear, and built my own Linux system up from a base Arch image.
- 🧪 **Breaking things on purpose:** I like knowing exactly how something fails before
  it fails on its own. Chaos is just testing without a plan.
- 🐧 **Currently:** learning Linux kernel development, one oops at a time.
- 💳 **Day job past:** ISO-8583, card authorizations, Kubernetes, and a lot of Go.
  Plenty of transactions, very little drama.
- ✈️  **Off the ground:** passed the private pilot written exam. The airplane is the
  one thing I promise not to tinker with.

**Stack:** Go · C · Java · Rust (dabbling) · Kubernetes · AWS · QEMU/KVM · LXD

### 🗂️ Portfolio / Showcase

- **[Three Years, Five Stacks: What I Built to Learn](dimes-showcase.md)** — a three-year side project
  (16 repos, ~750 commits) that started as a way to learn Kotlin and grew into a data pipeline,
  microservices, a Firefox extension, a Discord bot, and a Kotlin Multiplatform desktop client,
  across Kotlin, Go, Rust, and TypeScript.
- **[fantasy-sports-rs](https://github.com/Sectorbob/fantasy-sports-rs)** — *active, tinkered on as time allows.*
  A Rust SDK that puts Yahoo, Sleeper, and Fleaflicker behind one data model with an on-disk
  response cache, plus a terminal UI for managing and visualizing fantasy football leagues in one
  place. It's my way of learning TUI development.
- **[MPGuino: Del Sol Edition](mpguino-showcase.md)** — a fuel-economy trip computer for my 1995
  Honda Del Sol. I tapped the ECU's speed and injector signals and modified the open-source
  MPGuino firmware (C/Arduino) to drive an ST7735 color display. [Code](https://github.com/Sectorbob/mpguino_st7735_mod).
